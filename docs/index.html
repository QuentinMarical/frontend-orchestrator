frontend-orchestrator
Principe Règles Installer

Un seul skill pour appeler tous les autres.

frontend-orchestrator lit votre demande, choisit les bons skills de design, d’accessibilité et de déploiement, puis les enchaîne dans le bon ordre. Rien n’est copié : il ne charge que ce dont la tâche a besoin.

Installer le skill Comment il choisit

Choisissez une tâche, voyez la chaîne

    Vingt skills, un seul réflexe à retenir

    Quand plusieurs skills couvrent le même terrain, l’agent hésite ou les charge tous, et vous payez le contexte. L’orchestrateur tranche avant : un skill de direction créative, un ou deux spécialistes, une étape de contrôle.

    Il connaît les quatre modes d’un projet d’interface : créer, auditer, corriger, livrer. Chacun correspond à une chaîne fixe que vous pouvez lire dans le fichier.

    Quatre règles qui évitent les collisions

    Une seule direction créative
    Un skill qui pose des questions et un skill autonome ne travaillent jamais sur la même page.
    La typographie passe en dernier
    Elle corrige le code déjà généré, au lieu de lutter contre les choix de style.
    L’accessibilité valide après le code
    Un scan automatisé, puis la revue clavier et lecteur d’écran si la page est critique.
    Rien de sortant sans votre accord
    Un déploiement en production demande une confirmation explicite.

    Installer en une commande

    Le skill est un simple dossier. Copiez-le dans votre répertoire de skills, relancez l’agent, et la demande « fais-moi une landing page » déclenche la chaîne.

    Terminal
    # 1. l’orchestrateur
npx skills add QuentinMarical/frontend-orchestrator

# 2. les skills qu’il appelle (Claude Code)
git clone https://github.com/QuentinMarical/frontend-orchestrator.git
bash frontend-orchestrator/scripts/install-skills.sh

    Compatible avec les agents qui lisent SKILL.md

    Le skill suit le format ouvert Agent Skills. Les listes ci-contre viennent de sources publiques ; elles n’ont pas été testées une à une.

    Les skills appelés doivent aussi être installés sur l’agent choisi. Les plugins /plugin install ne concernent que Claude Code.
